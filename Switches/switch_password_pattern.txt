## Task
The objective of this program is to implement a secure combination lock using physical slide switches. The system requires the user to input a specific sequence of switch combinations step-by-step; successfully completing the sequence unlocks the system and lights up all LEDs.

## Implementation Details
1. Memory-Mapped I/O Setup: Defined base hardware addresses for LEDs (`0xff200000`) and slide switches (`0xff200040`) using volatile pointers for real-time register access[cite: 1].
2. Finite State Machine (FSM): Implemented a robust `passwordtest` function using a static `state` variable to track progress across sequential unlocking stages[cite: 1].
3. Reset & Error Handling: If an incorrect switch pattern is entered at any point, the state machine automatically resets back to `case 1`, ensuring security[cite: 1].
4. Output Feedback: The main loop polls the password test function continuously; when unlocked, it drives all LEDs (`0x3ff`), and keeps them off (`0x0`) otherwise[cite: 1]. Included header documentation linking to this file.

## Result
The code functions smoothly as a hardware-based password lock. Entering the correct sequence of switch states successfully triggers the LED indicator output.
