PROJECT DESCRIPTION: Switch-Driven 7-Segment Display Counter
CODE FILE: switch_ssdisplay_pattern.c
==================================================

## Task
The objective of this program is to read individual physical slide switches dynamically using a compact loop, calculate a running total based on active inputs, and render that calculated number onto the hardware 7-segment displays in real-time.

## Implementation Details
1. Memory-Mapped I/O Setup: Defined memory base addresses for LEDs (`0xff200000`), the 7-segment display (`0xff200020`), and slide switches (`0xff200040`) using volatile pointers to ensure direct hardware register access.
2. Optimized Segment Translation: Implemented a clean `switch-case` lookup function (`numbtossd`) featuring a single exit point (`numret`) to translate digits 0–9 into precise 7-segment hex bit patterns.
3. Dynamic Bitmask Polling Loop: Replaced repetitive manual checking code with an efficient `for` loop (`k = 0` to `9`) that uses bitwise shift masks (`1 << k`) to poll each switch pin and accumulate its weighted index value into `Total`.
4. Display Formatting & Linking: Calculated the units and tens digits, packed them into the display register, and maintained header cross-documentation linking to this file.

## Result
The code is now much cleaner, highly modular, and runs seamlessly. Flipping switches updates the accumulated total instantly, showing the correct value rendered cleanly across the 7-segment displays.
