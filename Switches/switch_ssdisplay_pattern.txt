PROJECT DESCRIPTION: Switch-Driven 7-Segment Display Counter
CODE FILE: switch_ssdisplay_pattern.c
==================================================

## Task
The objective of this program is to read individual physical slide switches, calculate a running total based on which switches are active using an accumulator pattern, and dynamically render that calculated number onto the hardware 7-segment displays in real-time.

## Implementation Details
1. Memory-Mapped I/O Setup: Defined memory base addresses for LEDs (`0xff200000`), the 7-segment display (`0xff200020`), and slide switches (`0xff200040`) using volatile pointers to ensure direct hardware register reading without compiler optimization caching.
2. Segment Translation Logic: Replaced cascading `if` checks with an optimized `switch-case` block (`numbtossd`) that cleanly maps digits 0 through 9 into their precise hexadecimal bit configurations for the 7-segment displays.
3. Switch Polling & Accumulation: Implemented an infinite polling loop that resets a running `Total` variable, inspects each switch individually via bitwise masks, and accumulates the weight of active inputs.
4. Display Formatting & Linking: Broke down the computed total into units and tens places, packed them into the hardware register via bit shifting, and included header cross-documentation pointing to this file.

## Result
The system operates smoothly and efficiently. Flipping switches updates the accumulated total instantly, showing the correct numeric value rendered cleanly across the 7-segment displays.
